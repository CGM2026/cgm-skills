# 现代占星 · 智能解读（公开版）

> 把星象与你的问题，变成一段贴近处境的解读，和一张可以分享的卡片。

## 简介

现代占星 · 智能解读是一款即开即用的占星占卜工具。无论你是随手起一卦，还是带着具体的星象与问题而来，它都能结合现代占星的内涵，为你写出一段有温度、有分寸的解读，并自动生成精美的分享卡片。

## 主要功能

- **随机起卦 / 自带星象**：两种方式任选。
- **围绕问题解读**：事业、感情、人际、自我成长，皆可发问。
- **多角度参考**：同一组星象可能呈现几种不同读法，供你对照。
- **精美卡片**：每次解读自动配图，便于收藏与分享。
- **稳重可靠**：以成熟的现代占星体系为依据，留有余地、不夸大。

## 如何使用

1. 安装后运行一次：`python3 scripts/selfcheck.py --fix`，看到「全部通过」即可。
2. 告诉它两件事：随机起卦还是已有星象、想问什么。
3. 获得解读与可分享的卡片。

## 温馨提示

占卜结果为启发式的象征性解读，供你参考与自我探索，并非事实预测或决策建议；涉及健康、财务、法律等仅作象征探讨，不替代专业意见。
