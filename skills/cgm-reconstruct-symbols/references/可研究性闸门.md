# 可研究性闸门

## 目的

判断现有语料能否支撑重构，而不需要发明失传教义。

## 评分维度

使用 `0` 表示缺失，`1` 表示薄弱，`2` 表示足够。

| 维度 | 核心问题 |
|---|---|
| 成员完整度 | 能否识别大多数成员？ |
| 体系边界 | 能否与邻近体系分开？ |
| 使用密度 | 每个成员是否有多条可用陈述？ |
| 成员区分度 | 文本能否区分成员，而不是重复泛泛吉凶？ |
| 条件覆盖 | 重要条件和组合是否保存？ |
| 文本完整性 | 相关章节是否大体完整？ |
| 平行文本补证 | 空缺能否由可靠的同期材料检查？ |
| 来源可追溯性 | 每个结论能否回到具体来源？ |

## 评级

- **可完整研究**：成员完整度、文本完整性、来源可追溯性均为 `2`，且其他维度没有 `0`。
- **可局部研究**：任一关键维度为 `1`，或多数成员、核心机制需要依靠平行文本补证。不得声称完成整个体系重构。
- **不可研究**：成员完整度、文本完整性、来源可追溯性中任一项为 `0`。

不得机械相加总分。成员完整度、文本完整性和来源可追溯性属于关键维度。

## 补证规则

只有同时满足以下条件才允许补证：

1. 平行文本在时代和传统上足够接近；
2. 每条新增内容都标明来源；
3. 分歧保持可见；
4. 补证后的语料不得冒充某位作者的原始完整体系。

若补证提供了多数成员或任何核心组织规则，体系必须降级为“可局部研究”。

体系对称性永远不能证明缺失成员的含义。
