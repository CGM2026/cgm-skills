# 历史现实还原

## 核心问题

不断追问：

> 当时的什么实践、制度、身体观、物质过程或关系，使这条符号陈述变得可以理解？

## 各领域可调用的学科

| 领域 | 可调用知识 |
|---|---|
| 社会位置 | 社会史、政治史、法律史、经济史 |
| 家庭与关系 | 亲属制度、婚姻史、继承法、家庭史 |
| 身体与疾病 | 医学史、体液学说、解剖观念、治疗实践 |
| 宗教 | 仪式史、庙宇经济、神职制度、崇拜史 |
| 劳动与技术 | 劳动史、工艺史、军事史、技术史 |
| 物质对象 | 物质文化、冶金、农业、贸易 |
| 心智与情绪 | 情感史、修辞学、古代心理哲学 |
| 语言 | 语文学、历史语义学、语用学 |

## 历史还原卡

每条原始陈述记录：

1. 字面对象或事件；
2. 行动者及其位置；
3. 资源、权利、义务和限制；
4. 实际发生的动作或过程；
5. 时间形态：突发、周期、累积或持续；
6. 边界变化：连接、分离、转移、固定或排除；
7. 历史支持；
8. 竞争性解释；
9. 不确定性。

过程描述必须由独立于预期符号含义的历史材料支持。不得先认定某颗星或某个术数符号“应该是什么”，再决定哪些现实特征值得保留。

## 来源优先级

优先使用：

1. 同时代原始历史材料；
2. 可靠校勘本与专业辞书；
3. 同行评审研究；
4. 大学出版社与学术百科；
5. 可信博物馆或研究机构资料。

实践者注释可以证明后世如何理解传统，但不能自动证明原始时代的含义。

使用平行文本时，记录时间、地域、语言和传承距离。若跨越明显教义或翻译断裂，不得标为同期平行证据，只能作为接受史或历史背景证据。
