# 证据与报告输出

本文件是唯一输出契约。

## 输出语言

- 默认使用简体中文。
- 只有用户明确指定其他语言时，才使用其他语言。
- 原文引文可以保留原始语言，但必须附中文译文或中文说明。

## 默认交付

默认交付两份独立报告：

1. `专业研究报告.md`
2. `符号语言教科书.md`

若用户没有要求写入文件，也必须在回答中用两个一级标题明确分开。

两份报告共享同一研究底稿，但目标不同：

| 报告 | 回答的问题 | 主要读者 |
|---|---|---|
| 专业研究报告 | 凭什么这样判断？ | 研究者、审查者 |
| 符号语言教科书 | 怎样用最短时间看懂整套符号语言？ | 零基础成人学习者 |

不得把专业报告简单删节后冒充教科书。

# 第一份：专业研究报告

## 一、研究结论摘要

简要说明：

- 研究对象及边界；
- 核心洞见候选及状态；
- 最可靠的规律；
- 最大冲突与限制。

## 二、来源与文本层审计

说明出处、完整性、范围、内部文本层和局限。

## 三、候选体系与用户选择

展示全部候选、可研究性、不可用对象及用户选择。

## 四、体系边界与证据账本

列出成员、排除项、嵌套体系、文本层、语料覆盖、来源编号、谓词、条件、领域和证据等级。

## 五、历史现实还原

解释证据簇背后的制度、生活、身体、物质和关系过程。

## 六、领域规律与跨领域候选

先呈现各领域规律，再提出跨领域候选。每个候选包括：

- 最小关系；
- 独立支持领域；
- 对照符号；
- 反证条件；
- 反例；
- 残余；
- 证据等级；
- 当前状态。

## 七、核心洞见竞争与裁决

至少比较两个体系级候选，说明：

- 各自能解释什么；
- 解释不了什么；
- 哪个具有更强的解释压缩力；
- 哪些材料会推翻最终候选；
- 该洞见适用于哪个时代或文本层。

## 八、词汇与句法证据

展示符号的实际组合行为：

- 单个符号可能承担的语言功能；
- 组词规则；
- 造句规则；
- 多套系统之间的接口；
- 不支持语言类比的反例。

## 九、留出检验

说明封存了什么、揭示前做了什么预测，以及结果属于支持、混合、失败还是空泛预测失败。

## 十、被拒绝与被修订的候选

保留候选版本、拒绝证据、原因和替代方案。

## 十一、最终边界

从以下结论中选择：

- 具有可靠核心洞见和跨领域规律的系统；
- 部分自洽但包含历史层累的系统；
- 编者综合体系与早期来源层不同；
- 多套相互作用但不能化约为单一语言的体系；
- 无法完整重构的残缺体系。

不能因为每个成员都有整齐定义，就称体系完整。

# 第二份：符号语言教科书

执行 [洞见型短教科书.md](洞见型短教科书.md)。

写成短篇洞见手册，不写成课程教案。追求认知压缩率，不追求教学设施齐全。

## 一、开篇导读提示词

提供一段可复制提示词，让 AI 只依据本书，以苏格拉底式提问逐点教授。每次只讲一个知识点，先问后讲，以现实经验和例子帮助理解。

## 二、一句话点破整套体系

用一句话说明这套体系把世界模拟成什么。随后简要说明：

- 它最关注什么；
- 为什么需要这些符号系统；
- 这个概括的边界。

没有可靠核心洞见时，明确说明无法统摄。

## 三、整套语言怎样工作

先捕捉目标书中参与当前研究对象的全部符号系统。用一张总图或短表说明：

| 符号系统 | 映射现实中的什么 | 负责什么 | 怎样与其他系统交互 |
|---|---|---|---|

必须说明这些系统最后如何共同构成对世界的描述。

## 四、逐套拆解符号系统

每套系统只讲：

1. 它做什么；
2. 它影射现实中的什么；
3. 为什么会形成这种映射；
4. 古代怎样呈现；
5. 现代可以怎样理解；
6. 一个目标书中的例子；
7. 最容易发生的误读。

必要时再拆成员，但不得退化为孤立关键词表。

## 五、综合案例

至少用一个目标书中的完整案例说明：

```text
现实问题
→ 每套符号系统分别提供什么
→ 它们怎样互相限制或修饰
→ 最终怎样形成判断
→ 哪一步最容易被误读
```

## 六、最后压缩

简要总结：

- 这套语言最擅长看见什么；
- 它天然忽略什么；
- 最值得记住的三至五条关系；
- 哪些内容仍无法解释。

## 七、知识扩展提示词

在全书最后提供一段可复制提示词。它必须要求 AI：

- 保持本书核心洞见和系统分工不变；
- 先说明知识点属于哪套系统以及如何与其他系统交互；
- 重点扩展现实映射、形成原因、古代呈现和现代转译；
- 使用目标原典或专业报告中可追溯的证据；
- 区分原典明说、研究归纳、现代类比和不确定内容；
- 不用后世通说补齐，不虚构例子；
- 只有增加新理解时才增加篇幅。

## 教科书禁用结构

除非用户明确要求，不得加入：

- 每章学习目标；
- 练习、作业和评分；
- 每章重复的小结；
- 每章单独的 AI 提示词；
- 大段方法论、证据代码和研究流程；
- 不能翻译为现实含义的术语堆叠。

# 证据等级

| 编号 | 含义 |
|---|---|
| `T1` | 目标历史文本层直接陈述该关联 |
| `T2` | 年代接近、传承可追踪的平行文本支持 |
| `H1` | 独立历史研究解释其现实背景 |
| `D1` | 同一领域内多条材料支持稳定规律 |
| `X1` | 三个因果独立领域支持可证伪候选 |
| `P1` | 封存材料支持事先提出的非空泛预测 |
| `R` | 传统确有记载但模型无法解释的残余 |
| `C` | 现代构造性解释 |

证据等级表示支持类型，不表示数学概率。
