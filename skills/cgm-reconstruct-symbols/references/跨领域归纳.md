# 跨领域归纳

## 原则

各领域必须先独立还原，再比较关系。不得仅从社会比喻推出身体、物质或心理含义。

## 步骤

### 一、建立领域簇

依据语料自身划分社会、身体、心理、关系、物质、时间、宗教、语言等领域。

若社会、法律和经济材料描述的是同一个因果制度，只能算一个领域，不能拆成三个凑数。

### 二、恢复现实过程

把历史名词转换成有证据支撑的过程描述。过程描述必须来自独立历史材料，而不是预期中的符号含义。

错误示范：

> 士兵等于攻击性。

正确示范：

> 士兵使用有组织的强制力量，跨越或防守政治边界。

### 三、去对象化

暂时删除领域专属名词，但保留：

- 行动者和方向；
- 资源流动；
- 边界变化；
- 强制或自愿；
- 可逆性；
- 持续时间；
- 规模；
- 先后顺序。

### 四、形成领域候选

使用能够覆盖多条材料的最小关系，并明确哪些材料被排除。

### 五、比较不同领域

只有至少三个在因果上相互独立的领域出现相同关系，才建立跨领域候选。

### 六、与对照符号区分

优先使用原文主动对照的符号，或在功能、位置、明确分类中相邻的成员。不得根据现代印象擅自挑选“最近的符号”。

追问：

- 哪些证据只属于当前符号？
- 对照符号会给出什么不同预测？
- 两个定义互换后，解释是否仍然不受影响？

若可以无损互换，应收紧或拒绝候选。

### 七、声明可证伪条件

每个候选都必须说明：

- 它排除什么结果；
- 出现什么材料会推翻它。

如果一个关系什么都不排除，它就是空泛解释，必须拒绝。

### 八、检验留出材料

只能使用归纳前封存的材料，或用户后来提供的未读来源。

预测必须确实有可能失败。若任何结果都能被解释为支持，记录为“空泛预测失败”。

## 候选卡

| 字段 | 内容 |
|---|---|
| 最小关系 | 一句精简关系描述 |
| 支持领域 | 至少三个因果独立领域 |
| 纳入证据 | 稳定来源编号 |
| 排除证据 | 来源编号及理由 |
| 对照符号 | 原文有依据的替代解释与区别 |
| 排除与反证 | 被排除结果及可推翻候选的观察 |
| 预测 | 揭示留出材料前写下 |
| 留出结果 | 支持、混合、失败、空泛预测失败 |
| 残余 | 传统确有记载但无法解释的材料 |
| 状态 | 领域规律、跨领域候选、已拒绝 |

## 抽象方法示例

以下只展示研究形式，不代表任何具体传统：

```text
领域甲的对象，经独立还原后表现为受控转移。
领域乙的对象，经独立还原后表现为受控转移。
领域丙的对象，经独立还原后表现为受控转移。

候选：该符号表示通过获得授权的中介完成转移。
它排除：不经过中介的直接占有成为主要规律。
留出预测：新材料应更强调中介，而不是直接所有权。
失败条件：留出材料反复以直接所有权为中心，且不存在中介。
```

## 失败纪律

允许：

- 一枚符号包含多个机制；
- 多枚符号共享同一机制；
- 含义来自不同历史层；
- 矛盾暂时无法消解；
- 最终找不到共同结构。

不得通过增加无限抽象同义词，挽救薄弱模型。
