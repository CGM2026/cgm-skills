# 文本来源审计

## 目标

判断输入材料究竟能够合法支持什么结论。

## 必填信息

| 字段 | 记录内容 |
|---|---|
| 书名 | 用户提供的书名与规范书名 |
| 作者或编者 | 包含不确定性 |
| 大致年代 | 成书年代与现存传本年代 |
| 文化环境 | 地域、语言、政治与宗教背景 |
| 文本谱系 | 原作、异本、注本、译本、汇编 |
| 输入范围 | 全书、章节、节选、图片或笔记 |
| 版本 | 编辑者、译者、出版信息或底本 |
| 完整性 | 缺文、讹误、增补、删节 |
| 立场 | 实践者、注释者、编者或批评者 |

若文本属于汇编，不得给整部书强行指定一个作者和年代。先阅读 [汇编与多层文本.md](汇编与多层文本.md)，清点内部文本层。

## 来源类别

- `原典直接材料`：历史文本直接使用目标符号系统。
- `同期平行材料`：同一传统中年代相近的文本。
- `后世历史注释`：与目标文本存在明确时代距离的解释。
- `现代学术研究`：现代学者的历史重构。
- `现代实践者解释`：现代传统内部的诠释。
- `来源不明`：无法充分确认出处。

禁止混合这些类别。必须保留目标文本与后世见证之间的距离。

每个平行来源或补证来源都要记录：

- 时间距离；
- 地域；
- 语言；
- 流派或传承关系；
- 中间是否存在已知的历史断裂。

若来源跨越明显的时代、语言、地域或教义断裂，只能作为接受史或历史解释，不能直接作为同期平行证据。

## 停止条件

遇到以下情况时，停止或显著缩小研究范围：

- 输入材料没有可用出处；
- 译文遮蔽关键谓词，且无法检查原文；
- 节选缺少符号成员或多数使用情境；
- 文本混合多个流派，却没有标明来源；
- 只能依靠现代教义补全核心缺失。

报告继续研究所需的具体证据。
