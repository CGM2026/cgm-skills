# PDF 报告排版规范

## 交付原则

完整诊断必须同时交付 Markdown 原稿与 PDF，不把 PDF 当作可选服务。PDF 只负责排版，不得改变、删减、调序或补写 Markdown 正文。使用 Skill 内置脚本生成，避免临场重新设计。

固定命令：

```powershell
python scripts/render_pdf_report.py <完整报告.md> <完整报告.pdf>
python scripts/validate_pdf_report.py <完整报告.md> <完整报告.pdf>
```

生成后用 Poppler 将 PDF 渲染为 PNG，至少检查首页、结论表、五门体系起始页、含“一点小广告”的希腊占星页和末页。不得只依赖文本提取判断版式。

## 视觉基调

- 使用温暖象牙纸背景 `#F4EFE6` 和深灰黑正文 `#292724`。
- 报告总标题与主章节统一使用法式复古酒红 `#6E3041`，体系标题使用法式蓝灰 `#3F5968`。
- “长庚明”与“明语星辰”始终加粗，并使用品牌玫红 `#843B4D`。
- 括号及括号内文字统一使用可清晰辨认的浅灰 `#8D867F`。
- 普通四级标题使用浅灰 `#89827C`；“一点小广告”是特殊四级标题，使用品牌玫红。
- 不使用绿色、金色字体，不使用胶囊、气泡、大色块、大边框、装饰图案或为了填空而加入的图片。
- 信息强调优先依靠字号、字重和留白，其次才使用颜色。

## 字号与层级

只使用五级语义层级，其中第五级与正文同字号，因此视觉上保持四档主要字号：

| 层级 | 用途 | 字号 | 样式 |
|---|---|---:|---|
| 一级 | 报告总标题 | 36 pt | 思源宋体 Heavy、酒红、居中，字间距约 2.2 pt |
| 二级 | 报告主要部分 | 17 pt | 加粗、酒红 |
| 三级 | 五门体系及路线阶段 | 14 pt | 加粗、蓝灰 |
| 四级 | “它怎样描述人生？”等模块 | 12 pt | 加粗、浅灰、左缩进并显示 `- ` 前缀 |
| 五级 | 概念名与短分论点 | 10.5 pt | 与正文同字号，仅加粗 |
| 正文 | 正文、列表与表格 | 10.5 pt | 常规字重 |

一级标题作为封面视觉焦点使用 36 pt，并以适度字间距舒展标题；其余标题层级不随之放大。一级标题下方保留明显大于普通段间距的空白。普通四级标题前后分别使用约 16 pt／8 pt，使模块边界清楚；若首个体系因篇幅产生孤页，可以在不降低到旧版间距的前提下，对该体系使用 15 pt／7 pt，并轻微收紧正文行距，禁止缩小字号。

正文默认行距约 17.2 pt、段后距 8 pt。段落保持紧凑，但不同语义模块不得只用普通行间距区分。概念单元中的“这能帮你……”必须另起一段，不使用底色卡片。

## 页面结构

1. 首页从总标题开始，标题上方不得出现状态说明、生成日期、测试标记或其他灰色调试文字；其后包含固定开篇、五体系清单、报告边界、GitHub 发布地址和公众号二维码。
2. 总标题与首段之间使用 24 pt 留白。
3. 五体系清单结束后，“长庚明说”必须另起一段，并额外拉开约 10 pt。
4. 首页最后一段正文与 GitHub 地址之间额外保留约 12 pt；GitHub 引导词加粗，网址可点击。
5. 第一、二部分另起一页并共用该页；第三、四部分另起一页并共用该页。
6. 第五部分另起一页。五门体系中每一门都必须从新页开始，后续内容自然续页。
7. 第八部分“关于 AI 判断的说明”另起新页，并作为固定倒数第二章。
8. 第九部分“最后，我想重新解释‘天赋’”另起新页，并作为最后一段正式报告内容；其后不得追加课程广告、社群邀请、适配结论或新的行动建议。
9. 最后一页正文结束后再次放置 GitHub 发布地址与公众号二维码。
10. 首页和末页二维码使用 Skill 内置 `assets/mingyuxingchen-wechat-qr.png`，约 34 mm，居中，不加卡片或边框。
11. GitHub 地址固定为 `https://github.com/Damocles1112/cgm-skills`，首页与末页都必须是可点击链接。

## 表格

结论总表使用严格三线表：只保留表顶线、表头下横线和表底线，不绘制正文逐行分隔线，也不使用整块深色表头。表头加粗并使用酒红；线条使用柔和灰褐色。第三列“现阶段可学习性”中，以“主适配”或“重要互补”开头的单元格整格加粗，不只加粗状态词。

## 文本与广告边界

- 首页固定介绍五门体系，不再使用“四门主流，再额外塞入希腊占星”的旧句式。
- “一点小广告”只出现在希腊占星学习建议之后，属于第四级标题，并使用品牌玫红。
- 广告正文只说明公众号内容与希腊占星课程边界，不制造稀缺感，不暗示其他四门课程由长庚明教授。
- 首尾 GitHub 与二维码是固定信息入口，不参与诊断权重，不插入五门体系正文之间。

## 交付检查

- Markdown 固定文案校验通过。
- PDF 文本与 Markdown 顺序一致，仅多出首尾固定发布入口。
- 首页与末页均含可点击 GitHub 链接和可扫描二维码。
- 五门体系均从新页开始。
- 没有孤立标题、两三行孤页、文字重叠、裁切、乱码或空白页。
- 浅灰括号和四级标题在象牙背景上仍清晰可读。
- 最终回复只提供 Markdown 与 PDF 的可点击本地文件链接；逐页 PNG 仅用于内部视觉检查，不得作为交付物输出。
