# 手机与便携阅读副本

默认电脑端交付完整案例库工作页。手机远程桌面操作电脑浏览器，也使用完整工作页。手机通过聊天调用电脑、随后打开附件时，交付案例库生成的阅读副本，不顺手生成旧静态展示页。

阅读副本是导出时的快照，包含当前案例全部已制作盘式、已有图层、笔记及档案。可以切换已有盘式和图层、打开笔记与档案正文、调整阅读显示并生成 PNG/SVG。显示选择仅供阅读，不写回电脑案例；不保存内容修改，不自动同步电脑的新记录。缺少的案例或未计算的结果交给 Agent 在电脑端查询或计算，再重新生成副本。

沿用完整工作页的字体、颜色、工具位置。需要新增、修改、删除、保存或重新计算的按钮置灰并注明原因；档案的编辑入口在副本中显示为查看，打开完整只读正文。个人标识、图片匿名等只影响导出结果的输入仍可使用。副本标明内容截至时间；此提示不进入导出图片。

当前没有手机直连电脑案例库的访问入口，也不提供离线修改后回传合并。不得把电脑的 127.0.0.1 地址描述为手机可直接打开的链接。附件预览若不执行脚本或不允许保存图片，提示用支持脚本与下载的浏览器打开；仍受限时，Agent 在电脑端完成查询或用户授权的修改、导出图片，然后返回更新副本或图片。未实测宿主手机预览，不宣称其完整兼容。

阅读副本包含案例的出生资料与全部已有记录；不要把图片匿名设置描述为 HTML 匿名。程序许可和第三方声明随副本保留。生成副本不更改电脑案例记录。
