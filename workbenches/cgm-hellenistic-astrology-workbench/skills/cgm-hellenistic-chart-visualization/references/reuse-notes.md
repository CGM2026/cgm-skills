# 复用与适配

2026-09-05 从用户指定的 Astrologer 本地工作区提取；该工作区含未提交改动，提取使用当时文件内容，未更改项目。文件哈希见 source-snapshot.json。

- `assets/chart-geometry.js` 原样复用 `apps/desktop/src/renderer/chart-geometry.js`：坐标、圆弧、引线、圆周避让。
- `assets/chart-wheel.js` 提取 `renderer-chart.js` 中单轮盘相关函数与 `renderer.js` 中符号、颜色和半径常量；去除 Electron、案例管理及解释依赖。
- `assets/wheel.css` 提取 `styles.css` 的轮盘样式，补充选择态与逆行标识。
- 当前符号常量保留源项目集合，但适配器只传入上游校验通过的七星、四轴和两签点，不启用外行星或其他附加点。

适配修正：主宫制映射包含等宫制；不等宫的宫号使用相邻宫头的真实中点；界环读取计算 skill 的实际表格而非源项目默认表；扩大 SVG viewBox 以包含外围签点；增加逆行标记、点选详情和标准 SVG 命名空间。

界表由 Python AST 提取计算器中的字面常量，不执行计算器，也不依赖 pyswisseph。若未来计算器将表改为动态加载，应一起更新提取逻辑；不可静默退回默认界表。

浏览器只改变显示状态，不重新排盘。图形数字取度分、表格取度分秒，均向下截取显示精度，详情保留原始黄经。两签点编号按黄经排序，并在图下给出编号对照。

当前几何沿用源项目的分组避让。密集排列应核对文字遮挡；符号错开后的角度不得用作黄经、宫位或相位计算。


## 编辑与删除图层

点击图层编辑可重命名，并在窗口左下角使用红色「删除图层」。点击后先确认删除范围：此图层及其全部笔记和记号一起清空；取消不改变数据。确认后走现有保存及冲突处理；删除当前图层后回到原始盘。其他图层、案例备注与分析反馈保留。阅读副本不提供可写删除。
