# 既有纸面工作页与专项流程

案例库保存规则见 case-library-v1.md；本文保留旧 HTML 工作流和已认可的详细版式。

笔记、Agent 标记与模拟数据的显示遵守 [统一内容与卡片规范](case-library-v1.md#统一内容与卡片规范)。笔记默认留在所属笔记图层，选择放为卡片后复用同一 `ChartDock` 选项卡组，与已有卡片并列且只显示当前一张；不得把笔记另行追加为页面的纵向分隔区。横排与竖排遵守同一规则。

所有盘式共用的卡片关闭图标定位在卡片右上角，与正文标题共享顶部起点，不占独立的一行。标题区域预留图标宽度，长标题可以换行。定位规则绑定卡片本身，不能依赖卡片位于旧 `.workspace` 容器；横排与竖排一致。

盘式入口统一为无下划线的标题行：左对齐显示当前完整名称，右对齐以同字号、更淡颜色显示“更多盘式”；弹窗显示该案例全部已制作盘式并沿用原保存后跳转规则。名称为本命盘、行运盘、返照盘、十年九月运盘、法达星限盘、黄道释放盘。正文中技法名称及下方卡片选项卡保持原有形式。竖排且没有卡片选项卡时，标题行上方增加分隔线；选项卡出现后自动隐藏，横排不显示。

工作页盘式标题行上、下间距约8px，去掉旧工作区底部额外留白。宽屏将原盘面显示控件上移到黄道、宫位等排盘设置下方的左上角：相位图式切换（其他盘式为已有专用入口）在前，界、签点、虚点、小行星随后按两行两列左对齐，签点类别位于专用入口上方；相位口径入口紧随图式切换。使用轮盘左上方空白区域，轮盘铺满左侧可用宽度，不以窗口高度限制尺寸，去掉工作区顶部额外间距；底部只留签点图例。组件只移动一次，事件、状态和笔记图层锁定沿用原逻辑；窄屏恢复原位，竖图导出克隆恢复纵向底部控件布局，横图沿用左右布局；两种导出均移除操作控件。

## 输入与边界

- 输入为 `cgm-calculate-astrology-chart` 生成的完整 `chart-facts` v4 文件。已有文件时直接渲染；只有时间地点时先交给计算成员，沿用套件配置。
- 渲染器自动运行计算成员的校验器。v3、Astrologer 原生案例 JSON 或截图不能冒充 v4；缺失数据交回计算层处理。
- 首次显示、黄道岁差和当前宫制来自本案例已校验事实。个人传统预设只在点击时应用；历史浏览器全局偏好不能覆盖新盘事实。默认盘的事实与输入完全一致；切换黄道、宫位或界表时，针对同一时间地点重新计算并校验对应快照，不用图形坐标替代计算事实。
- 黄道、岁差、界表、昼夜与签点公式来自输入快照。界环从同级计算 skill 的源码读取界表，并核对点位界主；不另算黄经、改变公式或添加解释分数。
- 星体符号可以为避免遮挡而错开，定位细线与刻线保持真实黄经。本命盘使用单轮；行运盘默认绘制内层本命星体与外层行运星体。宫位分界线延伸到原有签点环，宫位、四轴、签点和界环均以本命事实为基准；缩小的内圈只为双层星体留出空间。开启虚点或小行星时，本命层和行运层按同一选择同步显示。行运盘目前不提供相位图式，也未计算跨盘相位。
- 行运双盘的内外层占星符号采用相同字号；内层星体位置沿径向外移，双层分隔圆同步外移，外层字号适度收小。度数与符号保留各自的径向间距；这项布局只作用于行运双盘，不改变本命单轮盘。
- 行运双盘工作稿可用 `--input <行运 chart-facts v4> --natal-input <本命 chart-facts v4> --natal-page <已有本命 chart.html>` 生成。行运事实独立计算与校验；本命事实作为关联副本保存。生成时会给指定本命页的盘式栏加入行运页链接，以便双向切换。
- 行运盘的“行运查询”按钮不提供查询文字框或手动条件表单。Agent 从自然语言明确时间范围、行运星体、宫位／星座、顺逆、相位对象与容许度，按当前盘面设置运行 `scripts/run_transit_agent_query.py`。计算结果写回当前 HTML，并按 `references/transit-agent-query-v1.md` 的统一结果弹窗呈现；无记录时按钮才提示用户回到 Agent。结果列表每页 5 段、最多 8 页，时间轴不是默认版式。只有当前显示的本命签点可作相位对象，不提供行运签点。已有旧版结果卡片仍可读取和关闭。搜索程序按 5、15 或 60 分钟采样，极短命中区间可能遗漏；Agent 应在答复中说明计算口径和这一限制。
- 返照盘使用 `scripts/render_return_chart.py --natal-input <本命 chart-facts v4> --natal-page <本命 chart.html> --output-dir <新目录>` 创建，首次生成时从当前时刻寻找下一次太阳返照，默认双盘并沿用本命地点。Agent 可通过 `--location-json <地点 JSON>` 指定返照地点，该文件需有 `location_name`、`latitude`、`longitude`、`timezone`（IANA）；只改变返照事实及单盘四轴，双盘底座仍用本命四轴。排盘成员负责以本命黄经求精确返照，返回时刻后再计算完整的返照 `chart-facts` v4；可视化成员只渲染经校验的事实。Agent 查询其他星体或时间范围时，先运行计算成员的 `calculate_return_query.py`（若指定了返照地点，附 `--display-timezone <该地点时区>`），再用 `scripts/attach_return_query.py --page <返照 chart.html> --query <结果 JSON>` 写入页面。“返照查询”位于盘面显示选项行右侧，单一弹窗分别说明如何发起新查询及显示已查询结果；结果每页五条，每次穿越独立列出，可跳转盘面、保存为卡片或同时执行。单双盘切换位于页眉盘面设置旁，单盘沿用本命单轮盘比例并显示星体度分。页面仅允许切换到已载入的返照时刻；单盘使用返照时刻与页面地点的四轴、宫位，双盘使用本命四轴、宫位和签点。返照笔记图层绑定当前精确时刻，导出副本省略重复时刻卡片。当前返照页属于工作稿，实际浏览器交互仍须用户验收。
- 十年运盘工作稿使用 `scripts/render_decennials_chart.py --natal-input <本命 chart-facts v4> --natal-page <本命 chart.html> --output-dir <新目录>` 生成。计算成员输出七种起运星的时间段，可视化成员沿用本命单盘排版并读取这些时间段。固定卡片提供概述与月日两种视图，标题行右侧分别显示「展开月日」「返回年限」；概述标题只显示大运、年限，月日标题只显示月限、日限。标题始终左对齐，不以黑色或下划线标记选中；右侧小字模式切换与层级小字下边缘对齐。卡片选项卡显示「十年九月大运」，盘式标题及选择弹窗显示「十年九月运盘」。概述默认显示当前大运下的完整年限表，月日默认显示当前月限下的完整日限表；点击标题可切换为完整大运表或月限表。表格按两栏逐行排列（第 1 项左、第 2 项右，以此类推），每项列当前层级的行星符号、完整开始日期和两位小数的起始年龄（实际生日年龄，由计算成员输出）；奇数项时末行右侧留空。符号列保持窄宽，紧凑无分隔线，不显示结束时间；表格占满卡片宽度，左右两组间保持紧凑间隔，日期与年龄列按比例伸缩且保留最小宽度；卡片宽度不足 360px 时自动按原时间顺序切为单栏。点击条目切换时段，并更新下级选择。标题选中不加下划线；符号保持紧凑固定宽度，日期、年龄采用有最小宽度的弹性列宽，三块之间保持相同的 6px 间隔；表格选中项使用一整条浅色（#eee8dd）背景，覆盖该条目的符号、日期、年龄及其间隔；符号与文字呈黑色，不加粗。取消滚轮与相邻五项限制，不设置内部滚动或分页。起运星入口位于盘面显示行右侧，默认昼生太阳、夜生月亮，可选传统七星。方法设置仍为当前工作稿，未定为套件长期默认。
- 行运工作稿须输出到与本命不同的目录。本命与行运的图层、笔记、查询卡片和原盘行运时刻各自写回所在 `chart.html` 的 `chart-archive-state`。同一文件在不同浏览器或 Agent 中打开时，须以该文件内的档案状态为准；重建页面须保留已有档案状态。
- 排盘设置中的展示偏好另存于 `output/chart-visualization-preferences.json`，供不同工作稿沿用。本命与行运分别保存覆盖项；行运尚未调整的设置继续继承本命偏好。已校验的 `chart-facts-v4.json` 不因页面操作而改写。
- 页面操作写回 HTML 依赖本机桥接服务 `scripts/time_adjust_server.py`（127.0.0.1:4852）。打开工作稿前运行 `scripts/start_time_adjust_server.ps1`；页面显示写入状态，并在旁边提供手动“保存”按钮。服务中断或同一档案字段发生并发冲突时，应处理“未保存”状态，不得称修改已经归档。首次打开旧工作稿时，将该浏览器的旧记录迁入 HTML。

## 生成与展示

1. 使用套件已配置的 Python（含 pyswisseph）和已安装的 Node.js。
2. 运行：

   ```text
   <python> <本skill>/scripts/render_working_chart.py --input <chart-facts.json> --output-dir <本轮输出目录>
   ```

   同级安装时自动找到计算 skill。特殊目录用 `--calculator-skill <计算skill目录>`；Node 不在搜索路径时用 `--node <node可执行文件>`。输出 `chart.html`、`chart-facts-v4.json`、`visualization.json` 和字体资源。文件已存在时换目录；只有需要更新本轮预览时使用 `--force`，不覆盖冻结案例。

3. 在 Codex 中，优先在右侧展示交互网页。用 `scripts/serve_working_chart.py --directory <输出目录>` 启动仅监听本机的预览进程，读取返回的实际 URL，再用可用的应用打开工具在右侧打开。此服务提供工作稿的字体文件；旧版 `serve_chart.py` 不提供，会导致浏览器回退字体。服务应使用可管理会话；Windows 后台启动时隐藏窗口。保留进程供本轮查看；不注册开机启动。
4. 浏览器已打开该盘时复用标签页；输入更新后重新生成并刷新。没有浏览器面板时提供 HTML 链接。渲染输出的 HTML 与其 assets 文件夹一起保留时可离线阅读；只移动 HTML 会丢失外部字体。需要单文件副本时使用案例库 `export --format html`，将资源内嵌。新时刻的计算仍需本地服务。
5. 需要对话内图片时，可用网页的“下载 PNG”，或已有浏览器工具截取完整轮盘后保存 PNG。截图前确保整个轮盘在画面内，截断或仅有局部不能作为完整星盘交付。导出 PNG 依赖浏览器；不要假称渲染脚本已经自动生成 PNG。
6. 给用户简短说明已显示的盘面和采用的设置。解释任务继续交回原分析成员，不因生成图而中断分析。

首次运行或绘图代码更改后查看实际截图，核对字体加载、符号、宫位方向、裁切及遮挡；输入变更但渲染代码未变时做与风险相称的核验。

## 页面文字规范

- 标题用朝华标题 A；日期、地点、设置、详情、笔记等中文正文用汇文明朝体。占星符号可使用专门的符号字体。离线 HTML 与本机预览均应提供字体文件。
- 日期显示为 `YYYY/MM/DD HH:mm`。
- 地点优先显示“省级简称·县级地名”，省略行政后缀及括号中的定位说明；如 `福建省宁德市柘荣县（县城定位）` 显示为 `福建·柘荣`。无可靠行政层级时保留原地名，不猜测。
- 地点后显示经度、纬度，均保留两位小数，格式如 `119.90°E 27.23°N`。完整地点与实际计算坐标保留在事实数据中，页面提示也保留完整地名。
- 日期、地址与署名在页眉右侧排成右对齐的三行，三行的右边缘与工具栏手形缩放按钮的右边缘一致，行距相等。第三行显示 `公众号｜明语星辰  设计`；“明语星辰”与“设计”之间保留两个空格。页眉分隔线在署名左侧留出间隔，标题保持在线上方；网页始终显示署名，整页导出可在弹窗中选择是否显示。
- 这套简写只影响页面排版，不能改变 `chart-facts` 的 `location_name`、经纬度或时区。
- 点击星体、四轴、签点、虚点或小行星时，位置行并列显示星座、度数和所在界。点击界环时，先显示该界的度数范围，再显示界主及其落座。
- 详情中的星座名、住所主名和界主名后接对应占星符号，星座符号使用与轮盘相同的字体栈；星体的位置行字号与详情里的“整宫制”等说明标签一致。
- 原始图层在页眉工具栏使用与笔记图层一致的手形“移动与缩放”图标及复位图标，远离可移动的轮盘；启用后用滚轮缩放、拖动平移，并可复位。
- 竖排时盘式标题行位于签点图例下方，图例隐藏时紧接盘面显示选项；横排时移到右侧卡片区域顶部。当前完整盘名左对齐，“更多盘式”同字号、更淡颜色且右对齐，不使用下划线。弹窗只展示已制作的盘式；导出图片中移除整个盘式入口。
- 页眉的排盘方式与图标在宽度足够时同一行显示；空间不足时图标整体换到下一行并左对齐。默认打开的页面宽度应保持同一行。
- 岁差与界表使用小号单选圆点，选中时圆环内显示实心小圆。岁差选项竖排且标签不折行；界表选项左右排列，位于岁差下方；各组与宫位制设置保持均匀间距。页眉排盘方式仍显示当前界表。
- 排盘设置顶部提供“个人传统”，只有用户主动点选后才应用于当前原始星盘。它不作为页面加载时的强制默认；新盘的算法默认须单独点击“将当前口径设为新盘默认”。希腊占星：恒星黄道、整宫制为首位、传统七星、显示签点与界；中世纪／文艺复兴占星：回归黄道、阿卡比特制为首位、传统七星、显示签点与界；现代占星：回归黄道、普拉西德制为首位、七星加三王星、隐藏签点与界、显示小行星。首位以外的宫位切换项保留已有选择，仍保持三项不重复；岁差沿用已有选择。此偏好不改变已校验的盘面事实，且不会在重新打开旧盘时覆盖后续手动设置。
- 新建笔记图层保留黄道、宫位制和星体范围等图层选项；宫位制只在排盘设置预选的三种中切换。岁差与界表不重复选择，直接继承新建时排盘设置中的当前值。笔记图层锁定排盘设置，页眉不显示设置图标；签点图例在笔记图层隐藏，底部注释工具栏与 IC 标注保持可见间隔。
- 签点图例固定在盘面“显示界、显示签点”等选项的下方，横向排列，宽度不足时自然换成第二行。福点排在精神点前，其余自定义签点随后；轮盘编号与图例编号一致。轮盘和下方图例数字共用当前类别颜色，不加色块；轮盘数字比下方图例数字更大，导出沿用该布局。
- 签点管理内置保罗所传赫尔墨斯七签点，以及瓦伦斯、菲米克斯、多罗修斯的已核对版本。古典条目的备注只写作者、书名及卷章编号；用户资料表导入而原典尚未核实的条目统一备注「待查验」。同名异式分开列出，无明确作者的差异版本以 V1 标识。新盘默认选择「常用」，其中只显示福点、精神点；其他内置类别首次选择时显示前10个（不足10个时全部显示），之后保留该类别各自勾选的签点，每类别同时显示至多10个；主动全部隐藏后不重新自动开启。已有工作稿读取旧的本地设置时，合并未安装过的内置条目，并保留用户改动。签点按分类选项卡管理：每页至多 30 个、至多 6 页，分类名最多相当于 5 个汉字的宽度；「常用」页固定不可删除，其他页可新增、改名、删除，删除时须将签点移到有足够空间的其他页。新建或编辑签点均可选择分类。公式、分类、例外及原典链接见 `references/built-in-lots.md`。
- 盘面显示选项简写为“界、签点、虚点、小行星”，与右侧“切换为  相位图式／常规图式”保持同一行；图式名称用黑色。仅在相位图式中，于切换按钮上方、右对齐显示当前口径文字；点击文字依次切换整宫、星光、现代，与黄道按钮的直接点击方式一致。保留星体整数度数、隐藏分数，把内侧空心圆向外扩张，并把宫位环调整为较薄的环；空心圆内默认只绘制星体之间的相位线，四轴与签点相位仅在点击对应对象后临时显示。同一星座内的合相不连线；虚点和小行星即使显示也不参与连线。六合与三合用不同深浅的绿色，四分与对分用不同深浅的红色，其余相位各用不同的蓝色。再次点击回到常规图式。导出图片保留当前轮盘图式，但不显示切换按钮与口径选择。
- 设置弹窗在“排盘设置”与“签点管理”之间提供“相位管理”。整宫、星光、现代三种口径分别勾选允许显示的具体相位。星光容许度按星体与四轴分别设置，以两端平均值判定；现代容许度按相位类型分别设置。星体、虚点、签点详情中的相位表与轮盘相位线共用这些筛选及容许度。详情卡片切换口径时，轮盘相位图式也跟随切换。
- 宫位环与宫位数字可点选。宫位卡片只显示宫头、宫尾所处星座与度数，以及宫内星体及其位置；不另列“跨越”字段。笔记图层可将宫位作为笔记对象。
- 相位图式中，第一次点击星体突出它与其他星体的相位线，不计算或显示星体对四轴、签点的相位；其余线降至很低透明度，再次点击才打开对象卡片。四轴和签点的相位线默认不绘制，只在点击对应四轴或签点时临时计算并显示它与星体的相位线，第二次点击打开详情卡片。所有相位线始终使用完整实线，不以线型、加减号、断线或“×数量”标注出入性质；出入性质只在详情卡片中呈现。第一次点击相位线突出该线、淡化其他线；再次点击打开以相位类型命名的卡片，在标题下另起一行列出相位两端，再显示入相位或出相位及距精准度数，不显示角距。相位线可作为笔记对象。

## 整页导出

- 页眉日期点击后直接打开下方的轻巧时间卡片，不再先在盘式切换文字之上展开，也不设置额外的投射按钮。卡片去掉可见标题、初始时间提示、外框和输入下划线；日期输入保留编辑能力，但不显示原生日历图标。调整控件靠左，与日期输入留出适度间隔；保存与关闭图标统一视觉尺寸，放在卡片右上角并与页面内容右边缘对齐；整组内容靠近上方分隔线。可按分钟、小时、天、周、月、年增减或直接输入时间，关闭后移除。试调必须调用本地计算器并整体刷新最多 42 种可用盘面数据，不得只替换日期文字。项目工作稿的本地桥接入口为 `scripts/time_adjust_server.py`，监听 127.0.0.1:4852；桥接未运行时明确报错，不呈现未经重新计算的盘。保存图标生成一份新的完整 HTML 与对应的输入、事实文件，旧案例保持原样；保存后在卡片内显示新案例文件夹名与“打开核对”链接，便于确认保存结果。日期组件不进入图片导出。
- 宫位环数字在界、签点显隐切换后保持原有中性色；星座环外四轴短刻度线使用黑色。
- 点击页眉导出按钮打开弹窗，可选择横图或竖图、预览并导出 PNG 或 SVG。布局默认选择竖图，可独立切换且不保存偏好；横图为完整的左右布局，竖图为完整的上下布局。横图解除右侧卡片的固定高度与内部滚动，完整导出当前内容；没有右侧正文时保留左侧轮盘的尺寸和位置，从右边裁掉空侧栏，不扩展左栏或把轮盘重新居中。两种格式使用同一整页画面；当前 SVG 封装整页位图，不能把其中的文字和线条当作独立矢量元素编辑。
- 弹窗可独立选择是否显示页眉的设计署名。网页中的署名仍显示，不随导出选项改变。
- 导出时排盘方式文字读取当前盘面状态，显示黄道、宫制和星体范围，不显示已移入设置面板的界表；界表仍决定轮盘事实。导出画面不保留工具图标占位，排盘方式行靠近页眉分隔线，署名显示与否不影响这一间距。
- 下方有详情卡片时，整页导出只保留当前显示的卡片正文，不导出卡片切换选项卡及其下划线。未展开的“关联笔记”只显示数量摘要；未展开的“相位”连同类型说明与表格均不导出。已展开的内容按当前状态保留。个人签名与联系方式位于所有卡片下方，由整行分隔线隔开。
- 案例档案以多条记录为基本单位。每条记录有标题、可空的记录日期，以及可分别为空但不能同时为空的“当时的分析”“当时的反馈”。弹窗先显示记录列表，另提供只读的“汇总分析”“汇总反馈”查看方式；时间轴模式暂不提供。记录可以新增、编辑、删除，汇总内容始终链接回原记录。
- 旧档案的“总体分析”“概况”文字按原分类保留为两条可编辑记录；迁移前的浏览器数据另存备份，不改写原文。用户可多选记录，将所选记录合成一张下方卡片；可再次选择不同组合，保留多张档案卡片并切换，不额外选择分析或反馈。只有一条记录时，卡片只显示一次记录标题；有多条时，以各记录标题区分，不重复加总标题。只有同一条记录的分析和反馈都存在时才显示这两个字段名。汇总分析与汇总反馈可分别作为独立卡片。弹窗始终留在原处，卡片保持与原记录关联；原记录改动后卡片更新。导出只保留卡片标题与正文，不导出档案编辑界面、操作按钮或空字段。其他卡片同样以对象名或笔记标题为主，不把工具和操作文字当作导出标题。
- 下方详情卡片的标题占完整行宽，不沿用侧栏的窄列标题布局。星体的宫位、黄经、运行等字段，以及星座、签点的成对字段，按左右两栏排；窄版缩小栏间距并允许长值换行，不能出现标题逐字竖排、字段重叠或横向溢出。签点标题与备注之间留足间隔；禀赋尊贵表在弹窗和下方卡片中按内容自然宽度排列，只适度增加列距，并保留同一格内符号的最小间隔，不强行铺满卡片，也不出现局部滚动条。导出图沿用这一布局，并去掉卡片关闭按钮。
- 笔记图层导出沿用同一页眉、匿名、设计署名和个人标识规则；只保留当前笔记图层的盘面与笔记内容，不导出原始图层中暂存的详情卡片、卡片选项卡或编辑工具。个人标识仍放在当前图层全部内容下方。
- 导出弹窗不提供“保留盘面设置”选项；盘面下方的显示开关与图式切换按钮在导出预览及图片中始终不显示。个人标识包括个人签名与联系方式，填写即显示、留空即省略，不提供字段勾选框，至少填写一项。输入内容仅用于本次页面会话中的导出，不写入排盘事实或长期配置。
- 个人标识只有一个位置：在整张导出图的全部盘面与卡片、笔记内容之后新增横贯整图内容宽度的分隔线；线下个人签名靠左、联系方式靠右，均使用黑色和原个人签名的字号。缺少任意一项时，另一项仍保持所属一侧的位置。右侧签点图例保持原有位置和对齐关系，不随个人标识下移。
- 导出弹窗提供匿名选项：开启时只在导出图片中把盘名改为“匿名”；还可选择把出生时间缩为 `YYYY/MM`，该选项只在匿名时启用。网页原盘名、日期及 `chart-facts` 不变。
- 导出弹窗的“隐私”分组还提供“不显示名称、时间与地点”：开启后从导出图中移除页眉身份信息，使轮盘成为主体；若同时启用设计署名，则把署名与黄道、宫位制所在的排盘方式行对齐，使用相同字号。匿名导出与不显示身份信息互斥，二者也都可以不选；出生时间仅显示到月份是匿名导出的缩进子选项，两个主选项之间不设分隔线。此选项不更改网页与排盘事实。
- 导出弹窗中“加入个人标识”与个人签名、联系方式同属“个人标识”分组。关闭总开关时禁用输入框并保留文字；打开后解锁，自动显示已有的非空文字。图片在个人标识下方保留18px空白后结束。
- 导出预览应检查标题字形顶部完整、设计署名与页眉分隔线有间隔、个人标识的整行分隔线与双栏对齐，以及匿名年月显示。PNG 与 SVG 下载复用预览的绘制逻辑。

### 签点类别与颜色

- 仅开启签点显示时出现「签点类别：名称」入口。竖排与图例同一行、右对齐、下边缘对齐；横排位于星盘左上控制区域第一行，即黄道文字下方、起运星或图式入口上方。页面类别入口始终黑色，只有签点数字使用类别颜色；横排四个显隐开关按界/签点、虚点/小行星两行两列排列。点击弹窗选择类别，轮盘和图例按同一类别显示并一致编号，所有公式仍在完整定义集内计算，允许跨类别引用。
- 类别颜色在签点管理的「类别颜色」及新建/编辑分类弹窗中选择；采用2行4列，每项同时展示色条、实际数字样例与中文名称。限定朱红 #a64625、浓金赭 #956200、松绿 #2d7046、青碧 #007f89、靛蓝 #2b56b4、赭橙 #ca6c22、藏青 #23465b、墨色 #39352e 八色。「常用」默认朱红，允许改色但仍不可删除。

- 数字以颜色区别为主，轮盘数字仅由18px微调为19px，浅底描边由2px减为1px。横竖图片及SVG导出完全移除签点类别切换按钮及类别名称文字，仅保留签点数字与图例及所选数字颜色。
- 星盘右下角专用文字入口（图式、相位口径、起始星座、起运星体、查询等）统一与「界、签点」显示开关同字号，不使用下划线；横排随既有控件移到左上。盘式标题和详情选项卡不适用此规则。

签点开启时，星盘的自适应边界必须包含签点数字，19px数字以23个坐标单位的垂直余量和每字符12单位的宽度预算包容字号、描边及字体差异；关闭时恢复无签点边界，不以固定下移代替边界计算。竖排图例每行最多五项，窄屏可少于五项；横排不设数量分行，按实际文字长度自然换行。横竖导出沿用这些边界与排布。
星座环采用低饱和纸面配色：火象 #DCAB92、土象 #DFC57C、风象浅鼠尾草绿 #BECBB5、水象灰蓝 #AEBFC8。界环继续由所属星座颜色与纸色逐层混合，不采用另一套元素对应。

### 卡片间距与签点避让（2026-10-01）

- 共用卡片规则必须同时覆盖原 workspace 和横竖布局的 chart-work-panel，不能依赖卡片迁移前的父容器。选项卡下划线到卡片标题至少24px；星体标题到星座与界说明14px；位置说明到禀赋尊贵20px。星座、行星、界及签点详情沿用同一卡片标题间距，关闭按钮继续与标题上缘对齐。
- 签点数字与引线一起避让四轴名称、四轴度数及其他签点数字；按真实黄道顺序安排数字，保留引线在星座环上的真实起点。每个数字都有连续外侧引线，数字前留小空隙；密集签点不得通过断开引线掩盖重叠。
- 更换签点类别或开关签点后，缩放模块同步新的完整盘面边界。未主动缩放时显示完整数字；主动缩放时按新边界换算原有视野，复位回到当前完整盘面。横竖页面和导出共用轮盘几何，不再沿用上一类别的裁剪范围。

## 编辑窗口退出规则（2026-10-01）

- 返回列表、关闭和 Escape 不得要求空白新建内容先满足保存条件。空档案、空笔记直接结束，不创建空记录，并清理对应编辑草稿；笔记已移除全部对象且标题正文均为空时也适用。
- 保存/完成仍校验必要字段。关闭时有效修改沿用现有保存；未完成或无效修改必须提供明确的放弃选择，取消放弃时保留当前输入，确认后仅撤销未完成修改，不删除既有记录。
- 图层空名称、签点无效名称/公式、重复宫位制选择不得形成无法退出的窗口。取消无效宫位制选择时恢复本次打开时的有效选项。

## 笔记数量与全部笔记入口（2026-10-01）

每图层最多新增到30条，旧超限记录保留并可编辑、删除，不允许增加；页面、Agent写入、导入和最终并发合并在保存时共同检查。外部最多三个已打开选项卡，标题最多5字符并按实际宽度省略，完整标题保留。新建及主动显示进入按打开顺序维护的队列；第四条移除最早打开选项卡，不删除笔记；重复选中已打开笔记不改变队列。批量新增按数据中新增顺序进入。各图层队列独立，会话内维护，刷新后按已保存顺序初始化最后三条。

“全部笔记”位于标签行右侧；弹窗左上显示数量/30，右上切换默认列表与网格。点击笔记只选择；右下“显示此笔记”关闭弹窗、显示正文和关联对象，与放为卡片独立。空弹窗和Escape可关闭，图层切换关闭旧弹窗；导出隐藏完整标签导航与操作入口，仅保留当前正文。
