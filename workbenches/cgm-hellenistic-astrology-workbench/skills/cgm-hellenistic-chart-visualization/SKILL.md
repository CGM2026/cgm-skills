# 希腊占星排盘可视化

默认通过本地案例库打开纸面星盘工作页。共用模板显示七星、四轴、签点与推运表格，支持图层笔记、绘图、自动保存和导出。下文旧 HTML 工作稿的生成方法保留用于导入与导出；库中记录的权威来源是 SQLite，不再写回原 HTML。


电脑端新建、整理、同步或补充案例，默认交付连接正式案例库的可编辑 HTTP 工作页，使用可视化成员 open 返回的地址。分享、手机聊天附件或明确离线阅读时再 export 阅读副本，并标为「阅读副本，不能保存修改」。经 HTTP 打开的导出副本仍是只读；普通静态文件服务不提供案例写入能力。用户无法编辑时，先核对页面类型与所连案例库，再给出该案例的完整工作页入口。

案例来源、可靠性与背景放在独立的「案例备注」，默认第一项；同案例跨盘式共用。读写方法见 [案例备注](references/case-remarks.md)。分析、反馈仍按记录与盘式保存。

## 本地案例库：默认协作入口

- 首次使用案例库或维护保存功能，读取 [case-library-v1.md](references/case-library-v1.md)。已有案例先 `library_cli.py list`，用返回的 view ID 操作；不要以文件路径猜测 ID。
- 使用工作区已有 Python，运行 `scripts/library_cli.py --library <案例库目录> open --view <ID>`，自动启动仅监听本机的服务。用返回的 URL 在 Agent 内的浏览器打开。
- 新建案例使用 `create --facts <已校验本命事实>`，默认一次建立本命、行运、返照、十年九月大运、法达、黄道释放六种盘式。行运以创建时刻初始化，页面原始图层打开时更新到当前时刻；返照默认出生地下一次太阳返照。`--mode <单一盘式>` 只用于补建或专项维护。旧工作页使用 `import <chart.html>` 导入，原文件保留。
- Agent 整理笔记用 `notes` / `objects` / `note-put`；整理案例档案用 `record-put`。修改已有内容必须附读取时的版本号。普通文字编辑不要读取、生成或覆盖整个 HTML。
- Agent 添加笔记、标记和模拟数据同样遵守 [统一内容与卡片规范](references/case-library-v1.md#统一内容与卡片规范)：笔记写入所属图层的结构化记录，默认只在该图层查看；用户选择放为卡片时必须复用 `ChartRelationNotes.dock` 和 `ChartDock`，与行运时刻、对象详情等并列为选项卡，每次只显示当前卡片。禁止把笔记正文直接追加为页面段落、分隔区或另建卡片切换逻辑；不要用旧 `layer.note` 字段创建笔记。
- 计算器负责星历、昼夜、返照、推运时间段、实际生日年龄；本成员调用其固定接口并呈现结果，不复制演算到浏览器。长时间表按起运选择生成，持久保存事实与口径，不重复保存大树。
- 所有盘式的图层、对象笔记、记录及草稿按 view ID 隔离；本命、行运、返照、十年九月大运、法达、黄道释放之间不引用或复制笔记。
- 页面输入先备份浏览器草稿，短暂停顿后写入数据库；收到事务提交确认后隐藏保存状态，不显示“已保存”字样。服务中断、同一字段不同修改时保留草稿并说明原因。正常切换页前立即保存。
- 同一内容冲突时暂停自动重试，复用页面的版本核对窗口：展示草稿与库中原文，可选任一版本或合并文字；独立修改一起保留，核对前的两份原文留作备份。损坏字段显示提示和可用历史恢复入口，不静默当成空记录。
- 校准本命时刻并保存时使用完整案例入口，建立六种盘式的新案例；原案例及其记录保留。已有案例 ID 不得复用给另一份出生事实。时段对象必须属于当前案例和盘式，并与计算器给出的路径和起止边界一致；旧无归属标记的对象仅在原记录内兼容读取和编辑。
- 共用字体与模板只存一份。独立 HTML 包含字体，体积较大，只在明确需要便携副本时导出；日常新建和编辑以案例库为准。
- 工作页每次打开默认按实际可用宽度自动布局：窄屏上下，宽屏左侧完整盘面、右侧盘式切换与一张当前卡片。工具栏手型图标下方的布局图标点击后直接切换为另一种排列，不弹出菜单、不保存偏好；刷新或切换盘式后恢复自动。导出弹窗可选择横图或竖图，默认选择竖图，不保存偏好；横图复用左右布局，竖图复用上下布局，个人标识位于全部内容之后并横贯整图。黄道释放起始星座按钮只显示星座名与符号，默认从本命福点起始的说明放在弹窗里。
- 导出内容过长时按正文与图块边界顺序拆成等宽图片，保持字号和全部内容；逐张生成并验证尺寸，提供页号、每张下载及整组 ZIP 下载。个人标识仅置于最后一张的底部，不生成空白预览或静默遗漏正文。
- 盘式入口使用无下划线的标题行：左对齐显示当前完整盘名，右对齐以同字号、更淡颜色显示“更多盘式”，点击打开全部已制作盘式的选择弹窗。完整名称为本命盘、行运盘、返照盘、十年九月运盘、法达星限盘、黄道释放盘。下方卡片选项卡保持原有形式；新盘式沿用该入口与保存后切换逻辑。竖排且没有卡片选项卡时，在盘式标题行上方显示分隔线；出现选项卡即隐藏，横排始终不显示该线。
- 盘式标题行与上方内容、下方卡片标签使用紧凑间距。宽屏把相位图式/该盘专用入口、签点类别放在排盘设置下方的左上角第一行，专用入口随后，界、签点、虚点、小行星开关按两行两列左对齐，复用原控件；轮盘铺满左侧可用宽度，不以窗口高度限制尺寸，并收紧盘面上方留白；底部只保留适用的签点图例。窄屏与纵向导出恢复原底部控件排列，笔记图层继续隐藏这些控件并锁定设置。
- 支持宿主浏览器的大页面模式，聊天悬浮/折叠由 Codex 或 ChatGPT 宿主提供；skill 不控制宿主界面。每次打开先用 `open` 确认本机服务和库地址，再用返回的 HTTP URL 打开，不把本地 HTML 文件路径当浏览器地址。
- `backup` 使用 SQLite 在线备份；恢复资料需要数据库和共用 assets。`history` / `restore-entry` 提供有限历史恢复。它们不替代用户的外部备份。

以下涉及“写回 chart.html”“4852 桥接”“离线文件直接编辑”的说明仅适用于尚未迁入案例库的旧文件。案例库 URL 使用 4860 服务及上述保存规则。

## 手机与便携阅读

按 [手机交付规范](references/portable-reading.md) 区分远程桌面与手机聊天附件。手机附件使用案例库 export，不另造旧展示文件：

```text
python scripts/library_cli.py --library LIBRARY export --view VIEW_ID --format html --output 阅读副本.html
```

副本含当前案例全部已制作盘式、已有图层、笔记与档案，支持阅读及图片导出；写入、保存和重新计算需电脑工作台。不把电脑本机链接当作手机可访问入口，不承诺未实测的附件预览兼容性。

## 按需读取

- 调整版式、导出规则、行运/返照查询或维护旧 HTML：读取 [working-page-details.md](references/working-page-details.md)。普通库中笔记编辑只需案例库协议，不加载全部模板规范。
- 输入只接收计算成员生成并通过校验的 chart-facts v4；时间、地点或事实缺失交回计算成员。图形位置不充当计算事实。
- 首次方法配置由相邻的计算成员自行完成，见其 `references/first-run-setup.md`。新案例初次显示继承已校验事实；个人传统只有点击时生效，不在加载时套用其他案例的黄道或岁差。修改新盘默认需使用设置中的独立保存按钮，不追溯改写已有案例。
- 高纬度不可用的宫制在设置中停用并显示原因。任何显示、试算或导出都不得静默替换当前宫位制。
- 分享前区分导出格式：PNG 的匿名仅影响图片；HTML／JSON 包含完整出生资料及记录。独立 HTML 内嵌资源，可离线阅读，动态计算与写回案例库仍需本地服务。工作页 SVG 是内嵌 PNG 的 SVG 容器，不能称为可编辑纯矢量图。页尾“关于与许可”默认收起，提供 AGPL-3.0-only 全文、第三方声明、源码入口及常见使用场景说明。图片导出不含许可区，公众号标识可自由开关，无须另补工具来源；分发含程序代码的 HTML 仍遵循程序分发要求。
- 沿用已认可的标题、占星字体、双栏表格、图层隔离和导出样式。用户只修改记录时直接更新字段，不重设计页面。
- 通用界面组件在 assets/working-page/work/ 中共用。新盘沿用 render_working_chart.py 等既有模板渲染器；旧版独立 SVG 只在明确需要时调用 render_chart.py。

签点类别切换、八色类别标记、横竖位置、笔记快照和导出静态文字必须遵循 `references/working-page-details.md` 的「签点类别与颜色」规范，Agent 添加标记也复用现有模块，不自行建立第二套显示逻辑。

## 存储与选定资料同步

使用 [存储与资料同步规范](references/storage-and-profile.md)。出生资料与用户选定的客观反馈通过 case-profile.py show/export/preview/apply 按需转交；明确来源/目标案例并展示差异，用户确认同一人及变更后执行。分析、讨论、研究、图层和排盘口径各自保留。单套独立可用，共享静态资源失败时使用完整本地资源。便携副本内部去重，既有离线查看范围保留。
