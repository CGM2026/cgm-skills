# 长庚明希腊占星工作台

围绕同一个人的星盘，把不同技法的观察、看盘笔记和后续反馈保留下来。你可以一边切换盘式、一边记录，再让 AI 根据已有资料协助整理复盘、备课或咨询提纲。

当前版本：**1.0.15**。作者：**长庚明**。占星在这里用于研究、教学和记录，不作为人生的绝对裁决。

档案的「按记录」「汇总分析」「汇总反馈」都支持逐条多选，再放到下方卡片。分析模式只展示选中的分析，反馈模式只展示选中的反馈；不同查看模式各自保留勾选。

此前优化：电脑端整理、同步和补充案例时，默认打开可编辑工作页，继续记录分析与反馈；需要分享或离线查看时，再导出明确标注的阅读副本。

此前优化：档案列表的「新增记录」与「放到下方」固定在窗口底部，浏览记录时随时可用。选好内容并展示为卡片后，窗口自动关闭，直接回到命盘查看；占星横向布局对应「显示在右侧」。

此前优化：档案中的分析、反馈栏增加明确的操作文字：收起时显示“展开 +”，打开时显示“折叠 −”，操作文字左对齐、字号一致，加减号独立对齐，沿用小号淡色样式。

此前优化档案阅读：列表先显示简短摘要，进入记录后查看全文；右上角可返回原列表，保留查看方式与位置。分析和反馈分别展开，空栏默认收起，长内容完整展开并随窗口滚动。删除入口位于记录左下方，以红色文字显示。

此前优化长期使用的存储：相同字体在本机按需复用，便携 HTML 内部去重，临时缓存限制容量。可以让 AI 按你选定的案例同步出生资料与客观反馈；分析、讨论和研究记录仍各自独立。每套工作台可单独安装，资料同步通过明确的案例与字段核对后进行。详见 [存储与资料同步](skills/cgm-hellenistic-chart-visualization/references/storage-and-profile.md)。

此前增加便携阅读副本：同一案例的已有盘式、图层、笔记和档案随文件带走，可以查看及导出图片。需要保存、增删改或重新计算的入口注明电脑端使用；手机聊天与远程桌面的交付方式也已分别说明。

## 可以怎样使用

### 围绕同一个案例，查看不同技法

从本命盘出发，继续查看行运、返照、十年九月运、法达星限与黄道释放。不同盘式各自保留笔记，让你能回顾每一种方法当时观察到了什么。

### 让笔记贴着你正在看的星盘

将观察关联到具体盘面对象，用不同图层保存不同问题或思路。你可以自己记录，也可以让 AI 读取这些笔记、按你的要求整理后写回。

> 「读取这个案例的本命和返照笔记，按我关注的问题整理一份提纲，并列出还需要补充的资料。」

### 让咨询与研究有后续

将自己的看盘判断、交流记录和后来收到的反馈存入同一案例。下次继续时，让 AI 先读已有资料，再帮助你归纳变化与待核实的问题；备课或咨询前也可以据此整理提纲。

### 在几种观察之间建立联系

你可以请 AI 把不同盘式中已经记录的观察并列整理，找出你反复提到的主题、相互呼应的记录或尚有分歧的部分。整理依据来自你保存的盘面与笔记，研究方法和判断由你掌握。

### 把研究成果带出去

选择盘面与笔记导出图片，用于讲解、讨论和案例分享；独立网页可离线查看，完整案例库可备份保存。教学材料、交流记录与个人研究可以围绕同一份案例持续积累。

## 包含内容

统一入口和两个功能成员放在同一 `skills/` 目录中，保持相邻：

- `cgm-astrology-workbench`：首次使用、方法确认与统一入口。
- `cgm-calculate-astrology-chart`：计算、事实校验、首次环境与方法配置。
- `cgm-hellenistic-chart-visualization`：本命、行运、返照、十年九月运、法达星限、黄道释放工作页与案例库。

排盘及展示可独立完成，不需要另装咨询、卜卦等分析成员。源码、模板、字体、小行星星历、许可及虚构示例随包提供。包内没有个人案例库、个人设置或 Python、Node.js 运行环境。

## 开始使用

阅读 [安装与首次使用](INSTALL.md)。也可以把下面这段话发给能读取文件并运行脚本的 Agent：

> 请从 https://github.com/CGM2026/cgm-skills 的 main 分支安装 workbenches/cgm-hellenistic-astrology-workbench 中的「长庚明希腊占星工作台」。先读该目录的 INSTALL.md，再读 skills/cgm-astrology-workbench/SKILL.md；检查运行环境，说明推荐方法并让我确认；使用虚构示例验证排盘与工作页。保留我已有的个人案例库和设置。

首次使用会说明推荐方案：恒星黄道、Fagan–Bradley 岁差、埃及界、整宫制。可以接受或更换，确认后保存为个人默认。出生日期、时区和坐标属于资料，不会被方法偏好改写。输入方法与个人默认冲突时，按提示手动切换；已有命盘保留原口径。

高纬度下部分宫制可能无法计算。界面会说明不可用的选择，并保留可用算法，不会暗中换成另一种宫制。

## 文件与分享

- 日常通过本机服务打开工作页，SQLite 案例库保存记录。使用包内备份入口保留整个库；单个导出文件不是完整案例库备份。
- `library_cli.py export --format html` 生成内嵌资源、已有盘式、图层、笔记与档案的阅读副本；文件大小随内容增加。可以查看与导出图片，修改和重新计算需电脑工作台。
- 图片匿名选项不等于 HTML 或 JSON 已删除个人资料。分享完整文件前检查出生资料、笔记及其他嵌入数据。
- PNG 可直接分享；工作页 SVG 是以 SVG 容器承载 PNG，不是可逐字编辑的纯矢量轮盘。
- 字体采用旧字形。严格规范字形的汉字教学或排印请先阅读 [字体作者说明](LICENSES/Font-Chaohua.txt)。
