# 长庚明八字工作台

把一个人的命盘、不同阶段的观察和后来得到的反馈放在一起，逐步积累成一份可以继续研究、复盘和分享的八字案例。你可以在书页式命盘上记录，也可以让 AI 帮你整理这些记录。

当前版本：**1.0.10**。作者：**长庚明**。命理体系在这里用于研究、教学和记录，不作为人生的绝对裁决。

本次优化档案阅读：列表先显示简短摘要，进入记录后查看全文；右上角可返回原列表，保留查看方式与位置。分析和反馈分别展开，空栏默认收起，长内容完整展开并随窗口滚动。删除入口位于记录左下方，以红色文字显示。

此前优化长期使用的存储：相同字体在本机按需复用，便携 HTML 内部去重，临时缓存限制容量。可以让 AI 按你选定的案例同步出生资料与客观反馈；分析、讨论和研究记录仍各自独立。每套工作台可单独安装，资料同步通过明确的案例与字段核对后进行。详见 [存储与资料同步](skills/cgm-bazi-visualization/references/storage-and-profile.md)。

此前增加便携阅读副本：同一案例的已有盘式、图层、笔记和档案随文件带走，可以查看及导出图片。需要保存、增删改或重新计算的入口注明电脑端使用；手机聊天与远程桌面的交付方式也已分别说明。

此前更新补齐工作页与独立 HTML 的“关于与许可”：默认收起，展开后可按使用场景查看说明、源码入口及完整许可。图片导出不包含许可区，公众号标识仍可自由开关。

## 可以怎样使用

### 沿着时间看一个案例

从岁运看人生阶段，再进入流月、流日，把观察记录在对应的位置。也可以直接问 AI：「帮我查看这个案例在某一天对应的大运、流年和流月。」让日期查询接上你正在做的案例研究。

### 把看盘时的想法留在盘上

为不同问题或研究方法建立笔记图层，将文字关联到你正在观察的盘面对象。你亲手写下的笔记，AI 可以读取；与 AI 讨论后形成的整理稿，也可以经你指定写回案例。

> 「把我刚才对这个流年的观察整理成一条笔记，放进当前研究图层，保留原有记录。」

### 带着后来发生的事情回来看

把当时的判断与后来收集到的经历、反馈分别存入档案。再次打开案例时，可以让 AI 对照这些资料，整理哪些观察得到了支持、哪些需要修正、哪些仍缺资料，逐步形成自己的案例积累。

### 研究分歧，也保留研究过程

遇到排法不同造成的差异，可以试算、查看变化，再另存一个案例继续研究。你可以给不同版本留下各自的观察，之后根据实际资料讨论差异。

### 从个人研究走向教学与分享

把整理好的案例笔记交给 AI，协助形成课堂提纲或回顾文稿；选择需要展示的盘面与笔记导出图片，也可以导出独立网页供离线查看。适合自学记录、课程演示与长期案例研究。

## 包含内容

三个成员放在同一 `skills/` 目录中，保持相邻：

- `cgm-bazi-suite`：首次使用、默认口径与统一入口。
- `cgm-bazi-chart`：排盘、事实校验与日期计算。
- `cgm-bazi-visualization`：工作页、笔记、案例库和导出。

程序源码、模板、字体、许可及虚构示例随包提供。包内没有个人案例库、个人默认配置或运行环境。解压不会自动安装软件或启动服务。

## 开始使用

阅读 [安装与首次使用](INSTALL.md)，检查 Python、Node.js 和计算依赖。也可以把下面这段话发给能读取文件并运行脚本的 Agent：

> 请从 https://github.com/CGM2026/cgm-skills 的 main 分支安装 workbenches/cgm-bazi-workbench 中的「长庚明八字工作台」。先读该目录的 INSTALL.md，再读 skills/cgm-bazi-suite/SKILL.md；检查运行环境，说明推荐算法并让我确认；使用虚构示例验证排盘与工作页。保留我已有的个人案例库和设置。

首次使用会展示推荐口径，让你接受或修改；确认后的选择才作为个人默认。支持的算法设置分为两页：

| 四柱排法 | 可选项 |
| --- | --- |
| 时间口径 | 真太阳时（推荐）、平太阳时、钟表时 |
| 子时排法 | 子初换日（推荐）、零点换日、早晚子时分排 |
| 年柱换年 | 春节子初（推荐）、立春交节 |

| 起运与小运 | 可选项 |
| --- | --- |
| 起运算法 | 分钟折算至天并舍去余数（推荐）、余数折算至小时、时辰折算 |
| 小运排法 | 固定起点（推荐）、时柱起算 |

已存命盘改变算法时，先试算并比较，再另存；原命盘与笔记保留。不同排盘工具结果有差异时，应先比对具体口径。未知时辰、历史时制及历法边界见计算成员的参考文档。

## 文件与分享

- 日常工作页通过本机服务打开，案例库负责保存；将整个案例库目录妥善备份。
- 案例库 export 生成内嵌字体与当前案例各盘式的便携阅读副本，可以移动查看已有图层、笔记和档案并导出图片；副本不写回案例库，也不是数据库备份。
- PNG 可直接分享；工作页 SVG 是以 SVG 容器承载 PNG，不能称作可逐字编辑的纯矢量排盘。
- 图片中的隐藏姓名、地点或时柱选项，只控制相应图片导出；分享 HTML、JSON 或案例库前仍需检查其完整资料。
- 字体呈现旧字形。需要严格规范字形的汉字教学或排印，请先阅读 [字体原作者说明](LICENSES/Font-Chaohua.txt)。
