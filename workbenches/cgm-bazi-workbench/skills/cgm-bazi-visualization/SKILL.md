# 八字可视化

默认在本地案例库打开已认可的书页风格，共用模板、字体和暖色背景。计算成员提供出生事实，SQLite保存权威记录，普通编辑不生成或改写整页HTML。新增功能的实现、浏览器测试和用户验收分别记录。


电脑端新建、整理、同步或补充案例，默认交付连接正式案例库的可编辑 HTTP 工作页，使用可视化成员 open 返回的地址。分享、手机聊天附件或明确离线阅读时再 export 阅读副本，并标为「阅读副本，不能保存修改」。经 HTTP 打开的导出副本仍是只读；普通静态文件服务不提供案例写入能力。用户无法编辑时，先核对页面类型与所连案例库，再给出该案例的完整工作页入口。

案例来源、可靠性与背景放在独立的「案例备注」，默认第一项；同案例跨盘式共用。读写方法见 [案例备注](references/case-remarks.md)。分析、反馈仍按记录与盘式保存。


## 跨项目与已有案例

首次在新对话调用时先读 [本机位置与跨项目使用](references/cross-project.md)。复用登记的运行环境、已确认设置和对应正式案例库；显式指定的位置优先。查询已有案例先 list 核对 ID，换项目不自动新建空库。

## 案例与协作

使用案例库先读 [案例库工作协议](references/case-library.md)。已有案例先list取view ID；新案例create生成岁运、流月、流日三个工作页，open返回本机HTTP URL。复用用户指定库，不猜ID、不终止其他库服务。

新图层用research读取完整text/version，再用research-put提交副本和baseState/baseVersion；增量导入使用research-import。保留未改字段及稳定ID，采用服务返回的完整合并状态。独立改动三方合并，同项冲突用conflictId/resolution核对，不能只换最新version覆盖旧稿。旧objects/notes/note-put/record-put仅兼容旧对象记录。

不同view数据隔离，同案例图层入口统一列出；跨view打开先保存再导航。出生事实校准后新建或复用对应事实案例，旧事实与笔记保留。网页没有日期定位，兼容日期计算仍交排盘成员timeline.cjs。

损坏记录保留原文，网页仅复制诊断交给Agent；定向历史恢复用research-diagnose/research-restore，核对view和当前版本，不增常驻恢复按钮。

## 图层、显示与导出

改交互前读 [笔记图层现行规范](references/research-layers.md)：原始盘只读但可查看关联笔记；原局图层只显示原局与笔记工具/内容，隐藏运势盘、十神/干支切换和完整运势入口；运势图层固定现场并将比较盘升为主盘，隐藏时间导航和盘式/展开入口。十神/干支放日期左侧。盘面不移动缩放，圈注/箭头可移动、缩放、旋转和弯曲；没有无对象整体笔记。

每层最多新增30条，旧超限完整保留、可改可删；网页、Agent、导入和合并后的保存共用限制。每层独立最多3个FIFO打开选项卡，全部笔记列表/网格只选择当前层记录；卡片与图层正文不叠加。

维护美工读 [书页现行规则](references/book-page.md)，姓名受限读 [姓名提示](references/name-guidance.md)。保留字体、题头、配色、柱名间距、窄屏与三盘格式。未知时柱用〇、旁注留空、不参加匹配；笔记选择以透明度和当前规定显色突出对象，不恢复早期框选。

修改设置/导出读 [导出与排盘口径](references/export-settings.md)：当前界面直接导出，两项互斥匿名和独立隐藏出生时柱；当前笔记关联时柱时禁用隐藏。个人标识仅在导出副本的色块右侧正文区显示且无分隔线，长图等宽分张。排盘设置为「四柱排法」「起运与小运」两页，五组算法选项；原始盘试算调用计算成员、另存案例；笔记图层只读。首次使用确认个人默认，后续冲突提示手动切换。保存个人默认和当前案例另存分别执行。

## 便携阅读副本

手机附件与便携阅读按 [手机交付规范](references/portable-reading.md)。用案例库导出一个含当前案例各盘式、已有图层、笔记和档案的阅读副本：

```text
python scripts/case-library.py --library LIBRARY export --view VIEW_ID --output 阅读副本.html
```

阅读与图片导出可用；内容编辑、保存和算法试算需要电脑工作台。不要以旧静态展示页替代阅读副本。桌面及远程桌面默认打开完整 HTTP 工作页。

## 旧静态页与交付检查

明确只需要旧静态展示HTML时在本成员目录执行：

```text
node scripts/render.cjs CHART.json assets/kimi-book-v1.json OUTPUT.html
```

输出内嵌同源JSON、字体子集，并附provenance；单文件可搬移。旧静态展示HTML不包含案例库图层和档案；需要便携阅读时使用上述 export，副本不支持写回与口径试算，且含完整出生资料；图片匿名选项不会改写HTML/JSON。模板位于assets/template/book.html，SHA-256冻结；更新模板先读 [模板交接](references/template-handoff.md)。历史design-proportion适配器已退出发布入口，原样稿另行保留。

缺完整calendarView或真实节气的数据交回计算成员升级/重排，不补近似日期迁就模板。核验实际加载的代码、元数据及资源；真实PNG/SVG/ZIP须下载解码、检查正文和接缝，静态或纯函数检查不替代实际图片。安装、发布与外部上传遵循本次明确授权，不能因源码已改推定安装完成。

## 存储与选定资料同步

使用 [存储与资料同步规范](references/storage-and-profile.md)。出生资料与用户选定的客观反馈通过 case-profile.py show/export/preview/apply 按需转交；明确来源/目标案例并展示差异，用户确认同一人及变更后执行。分析、讨论、研究、图层和排盘口径各自保留。单套独立可用，共享静态资源失败时使用完整本地资源。便携副本内部去重，既有离线查看范围保留。
