# 案例备注

案例档案默认先打开「案例备注」，直接编辑来源、可靠性、出生时间证据、人物或事件背景，以及卜卦的提问经过。短暂停顿后自动保存，长文随窗口展开；另三个选项卡为「记录汇总」「汇总分析」「汇总反馈」。

备注按案例保存，同一案例的各盘式共用；不同案例、八字与占星各自独立。它不进入分析或反馈的汇总卡片，也不参与出生资料交换。既有记录保留原内容，不自动搬移为备注。便携阅读副本带上已有备注，只供查看。

Agent 查询或修改使用本成员的独立入口：

```text
python scripts/case_remarks.py --library LIBRARY --view VIEW_ID
python scripts/case_remarks.py --library LIBRARY --view VIEW_ID --text-file 备注.txt --version VERSION
```

先读取原文和版本，保留不需修改的内容，再提交完整备注。备注上限10万字。不同版本修改同一备注返回冲突和库中原文，核对后再提交；页面保留草稿并提供两份内容选择，数据库保存先前版本。不要只换最新版本号覆盖另一份修改。
