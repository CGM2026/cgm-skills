# 导出与排盘口径现行规范

本文件适用于案例库工作页。案例库导出的便携 HTML 可查看已保存的图层、笔记与档案，也可导出图片；修改与试算交给电脑端。旧渲染器的静态 HTML 仅供展示。测试结论记录在对应版本的实测报告中；本文件不代替真实图片验收。

## 当前界面导出

直接导出用户选好的当前界面，不提供范围、版式切换或“附带当前内容”设置。原始盘保留当前展开状态和显示的卡片；笔记图层只保留当前笔记、关联对象行与记号，不混入原始盘卡片。保留页面的完整标题、字号、配色、对象显色和正文布局，不重建为缩小字号的独立排版。

工作工具、笔记工具、十神/干支选择入口、选项卡、全部笔记、编辑/关闭按钮、滚轮箭头、标记控制点及透明命中区不入图，也不留操作占位。仅移除操作，不删除标题、正文或关联对象。

## 隐私

“仅匿名姓名”和“匿名姓名和出生地点”互斥，均不选保留原名与地点。匿名仅改变导出副本，保持姓名内层定位结构，并按匿名字形校正墨迹位置；文件名也匿名。隐藏地点或设计署名后，导出题头信息区重新按内容高度排版，保留日期与姓名的原有基线关系，不沿用被删行的固定高度和顶部位置。笔记正文和档案不自动改写。没有只显示出生月份或删除出生日期的选项。

“隐藏出生时柱”独立于两项匿名选择。保留柱位和“时”标签，原局及运势比较区重复出生时柱的天干地支替换为灰色〇（U+3007），旁注留空；移除以出生时柱为端点的记号。流年、流月、流日等运势柱不隐藏，保存事实不改成时辰不详。

当前笔记关联natal:3及任何子项（时柱、时干、时支、十神或藏干旁注）时，禁用隐藏出生时柱，并说明“当前笔记关联时柱”。正在选择对象时按当前选择核对，生成入口再次检查，不能绕过禁用状态。

## 署名与个人标识

设计署名默认显示。个人标识总开关默认关闭，控制姓名/签名与联系方式的启用和输入；关闭时禁用输入框但保留文字，开启后填写即显示、留空即省略，不提供字段勾选框，至少一项有效才可生成。只在当前页面会话保留，不写出生事实或个人默认。

个人标识位于全部盘面、笔记和档案内容之后的正文区。左边界是左侧色块右缘加现有正文内距，右边界对齐盘面正文右缘；姓名左对齐、联系方式右对齐，上方没有分隔线或下划线。个人标识仅临时添加到导出副本，在预览与最终图片显示；普通工作页、笔记和卡片中不添加节点或空白占位，关闭导出不留残余。采用既有字体，字号16px、暖棕色#876449，上方留白24px；图片在标识实际底边下方18px处结束；分张时只出现在最后一张。

## 图像、字体与长图

PNG使用2倍像素。SVG封装同一PNG画面，不声称可编辑矢量。更改选项或关闭弹窗使旧预览及下载结果失效；完成结果不得回写到已失效的弹窗。

导出副本先准备当前文字的字体子集并等待字体、布局稳定，再按导出副本内的对象位置重新绘制当前记号，并测量图块与文字行保护区。采用开始导出时捕获的记号快照，不复用原页面的SVG位置和高度；不写回原有锚点或相对坐标。字体请求仅发送去重字符，不截断正文；临时字体使用独立别名，不能替换网页当前字体。

长内容等宽分张，不缩小字号，每张独立渲染，不先生成超高整张Canvas。分张结合图块/文字行保护及最终像素空白接缝；找不到安全切点时明确失败，不强行切开文字。预览显示页号，支持逐张PNG/SVG及整组ZIP。接缝、首尾、完整标题、关联行和末页个人标识须核对实际生成文件；纯函数、HTTP或ZIP样本检查不能替代此项。

## 设置与权责

排盘设置沿用书页配色与字体，用两个页签和文字单选项组织，只显示可选择的算法及当前选项的简短说明。四柱排法包含时间口径（真太阳时、平太阳时、钟表时）、子时排法（子初、零点、早晚子时分排）、年柱换年（春节子初、立春交节）。起运与小运包含分钟折算至天、分钟折算至小时、时辰折算法，以及固定起点小运、时柱起小运。具体算法与边界以计算成员 references/calculation.md 为准。

固定规则不作为设置项目。有来源的已校正太阳时属于原始资料处理；此类案例需核对钟表输入后重排，不提供重复校正按钮。时辰不详只能用明确标记的钟表日期参照，时柱起小运不可选，不补造时柱或精确交运日期。

首次使用在案例库首页确认推荐或自定义口径，保存于库父目录的 .cgm-bazi/settings.json；命令行可用 --settings 指定同一文件。默认配置有版本号，另一窗口修改后须重新读取，不能覆盖。后续自动排盘与个人默认冲突时停下提示手动切换，不静默改算。普通工作页设置读取当前案例的实际口径，不用个人偏好重写旧事实。

原始盘修改后先试算，显示四柱、顺逆、交运及小运方法差异；另存生成或复用一致事实的新案例，岁运、流月、流日三盘齐备，旧案例和笔记保留。设为以后新盘默认是独立按钮，单独保存，既不改写当前盘，也不要求先生成新案例。图层中的算法设置只读，不另存、不写个人默认。

试算凭据保留10分钟并绑定原view；更改选项或关闭弹窗使结果失效。当前笔记未完成保存时不能另存跳转。默认方法、当前案例和试算分别保持自己的状态。

旧 Kimi 渲染器的静态 HTML 内嵌字体子集及完整 JSON，仅供展示；手机交付应使用案例库的阅读副本，其中包含已有图层与档案，但不带重算服务。HTML和JSON保留完整出生资料，图片匿名不适用于它们。在线工作页使用完整本地字体，保证后续输入笔记的字形；图片导出按导出时的实际文字重新取子集。

排盘成员负责计算和校验；可视化负责入口、默认配置交互、呈现、存档及导出。套件/Agent负责资料补齐与明确用户的手动切换；不能使用内部手动参数绕过未解决的冲突。
