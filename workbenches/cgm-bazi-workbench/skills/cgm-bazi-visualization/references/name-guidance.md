# 姓名显示提示

保留完整原名，不改出生资料。英文多段默认名字首字母加完整姓氏，首个缩写点与字母一起放色块内；单段英文完整显示。中文优先等字号，必要时首字最多1.5倍。用户目前已认可整体样式及缩写点位置。

生成后在实际浏览器读取 `.masthead` 的 `data-name-needs-shortening`、`data-compact-name`、`data-name-geometry`，并查看截图；这些标志是检查线索，不能替代目视检查。注意姓名资料间隔、墨迹基线、字形缺失与越线。未能实测时明确“已生成，姓名排版尚未实测”，不称已通过。

仅在有必要时于助手回复中温和提示一次，不增加HTML弹窗、提示条或设置入口：

- 常规英文缩写：“页面按 J. Derrida 显示，完整姓名仍保留在资料中。”若用户已知规则无需重复。
- 中文实际省略：“这个名字在窄窗口里会暂时缩略，拉宽后可完整查看；如果你愿意，也可以指定一个展示昵称。”
- 极窄下字体偏小：“窄窗口下这个英文姓氏会显示得较小；可以拉宽页面查看，也可以告诉我你习惯的简称。”
- 字体缺字／排版未满足：“当前字体对名字中的部分字符显示不够理想。我保留了原名；可以换一个展示写法，再给你核对。”

不自行汉化英文名，不强迫改名，不把正常首字母缩写说成错误。昵称只用于展示，不覆盖原名。准确时区和地点不足应按排盘成员处理，不混在姓名提示中。配置表、计算规则、起运证据保存在说明和JSON，不添加到HTML。
